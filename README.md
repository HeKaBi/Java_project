# Game1

`Game1` 是一个基于 Java Swing 开发的横版动作射击游戏原型，整体表现参考《合金弹头》。

当前版本已经可以从开始界面进入游戏，连续游玩 3 个关卡，完成人质营救、武器补给、Boss 战与关卡切换。

程序入口：

`src/com/tedu/game/GameStart.java`

启动后会打开一个 `1000 x 640` 的窗口，标题为 `Game1 - Metal Slug Prototype`。

## 当前版本内容

- 3 个可游玩关卡，分别使用独立背景、地形引导图与 `wav` 背景音乐
- 玩家支持左右移动、二段跳、上瞄、下蹲、平台下落、射击、近战和手雷
- 地形高度采样、斜坡行走、双层平台与横向卷屏
- 普通敌兵、精英敌兵、飞机敌人、Boss 与对应受击判定
- 人质营救、补给掉落、武器解锁与拾取音效
- HUD、任务横幅、`GO!` 前进提示、Boss 血条与关卡转场黑幕特效
- 失败结算、通关结算与 `R` 键重新开始

## 关卡与流程

当前版本包含 3 个关卡：

- `第一关`：海滨地图，包含双层路径、人质奖励为重机枪
- `第二关`：洞穴风格地图，包含更多空中压制与 Boss 战
- `第三关`：最终关卡，人质奖励为火箭筒

当前通关规则：

- 击败当前关卡 Boss 后，直接切换到下一关
- 第三关 Boss 被击败后，进入任务完成结算

补充说明：

- 人质救出后会掉落对应补给
- 救出人质后，界面右上会短暂显示前进提示
- 飞机敌人进入战场前，会显示“敌机来袭”横幅

## 操作说明

| 按键 | 功能 |
| --- | --- |
| `Enter` | 在开始界面进入游戏 |
| `A` / `←` | 向左移动 |
| `D` / `→` | 向右移动 |
| `W` | 跳跃，可二段跳 |

| `2` | 切换重机枪（解锁后可用） |
| `3` | 切换火箭筒（解锁后可用） |
| `Q` | 在已解锁武器间循环切换 |
| `R` | 在结算界面重新开始 |

## 主要系统

### 玩家与武器

- 玩家采用上下半身分离动画，可同时支持移动、上瞄、开火和近战
- 当前武器包括：
  - `步枪`
  - `重机枪`
  - `火箭筒`
- 不同武器使用不同子弹、射速与 HUD 显示

### 地形与移动

- 地图支持根据红线引导图提取可站立地面
- 支持平地、斜坡、双层路径与额外平台
- 双层区域默认走下层，玩家跳起后可落到上层

### 敌人与关卡事件

- 地面敌兵会根据场景推进生成
- 部分关卡会生成飞机敌人与投弹攻击
- Boss 出现时会显示横幅提示
- 击败 Boss 后触发关卡切换黑幕特效

### 反馈与界面

- HUD 显示生命、武器、手雷、时间、击杀数、关卡进度和 Boss 血量
- 玩家血条默认绿色，低血量时自动变红
- 开始界面、任务横幅和结算界面已完成中文化
- BGM 和音效分开控制，音效略高于背景音乐

## 目录结构

```text
Game1
├─ src
│  └─ com/tedu
│     ├─ game        # 程序入口
│     ├─ show        # 窗口、HUD、渲染面板
│     ├─ controller  # 输入监听、主循环、关卡推进
│     ├─ manager     # 资源加载、运行时状态、音频、元素管理
│     ├─ element     # 玩家、敌人、Boss、子弹、特效、补给等实体
│     └─ text        # 对象与资源配置
├─ image             # 图片资源
├─ music             # 背景音乐与音效
├─ out               # IDEA 编译输出目录
├─ bin               # 手动编译输出目录
└─ Game1.iml         # IntelliJ IDEA 工程文件
```

## 运行环境

- JDK 8 及以上
- IntelliJ IDEA，或使用命令行手动编译运行
- 当前项目未接入 Maven / Gradle，属于纯 Java 工程

说明：

- 项目依赖本地图片和音频资源
- 建议从项目根目录运行，避免相对路径资源解析失败

## 在 IntelliJ IDEA 中运行

1. 用 IDEA 打开项目根目录。
2. 确认 `Project SDK` 已配置为可用的 JDK。
3. 运行 `src/com/tedu/game/GameStart.java` 中的 `main` 方法。
4. 建议保持工作目录为项目根目录。

## 命令行编译运行

在项目根目录执行：

```powershell
New-Item -ItemType Directory -Force -Path out\run | Out-Null
$sources = Get-ChildItem -Path src -Recurse -Filter *.java | ForEach-Object { $_.FullName }
javac -encoding UTF-8 -d out\run $sources
java -cp "out\run;src" com.tedu.game.GameStart
```

## 资源与配置

项目资源主要包括：

- `image/images/...`：角色、敌人、Boss、背景、子弹、爆炸、平台与补给贴图
- `image/前进特效.png`：右上角前进提示贴图
- `music/*.wav`：关卡背景音乐与一次性音效

核心配置文件：

- `src/com/tedu/text/obj.pro`：对象名称到 Java 类的映射
- `src/com/tedu/text/GameData.pro`：基础资源键值映射

资源加载逻辑兼容：

- 类路径读取
- 项目目录读取
- `src` 目录读取

因此最稳妥的方式仍然是从项目根目录启动程序。
